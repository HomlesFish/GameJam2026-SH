# BoatSound — 项目功能计划与实现

> 开船用声呐在水下找宝藏得分。俯视"雷达仪表盘"视角，相机始终跟随船。
> 本文档汇总各功能的**设计计划**与**实现状态**，供团队查阅与后续开发参考。
> 最后更新：2026-07-04（移动 / 相机 / 雷达声呐 / 听声 / 旋转扫描线 / 声呐扫描环 已实现；拾取计分等待办）。

## 1. 游戏概述
- **主题**：玩家驾驶船只在雷达式仪表盘上移动，用声呐探测水下宝藏并拾取得分。
- **视角**：俯视 2D（正交相机），相机紧随船只、船基本保持在屏幕中央（雷达中心感）。
- **核心循环（目标）**：开船 → 用声呐看/听周围物体 → 切换频段定位宝藏 → 拾取得分。
- **引擎**：Unity 2022.3.50f1c1（LTS），URP 2D 管线。

## 3. 功能清单与实现状态

状态图例：✅ 已实现并入库 · 🔧 已实现、需场景接线 · ⬜ 待办

### ✅ 船的移动 / 惯性 / 抛锚 — `BoatController`
- **规则**：
  - **加速（W）**：按住 W，速度持续增加直到 `maxSpeed`；松开不自动减速（保持滑行）。
  - **转向（A/D）**：持续按住超过 `turnDelay` 后才开始以 `turnRate` 持续转向，松开立即停；点按（不足延迟）不转向。
  - **抛锚（Space）**：有速度时按 Space，速度在 `anchorDuration` 内线性降到 0，期间 W/A/D 无效。
- **关键文件**：`Scripts\Player\BoatController.cs`。Transform + 手写速度积分（不用 Rigidbody）。
- **可调参数（Inspector）**：`acceleration=3`、`maxSpeed=6`、`turnRate=90°/s`、`turnDelay=1s`、`anchorDuration=2s`、`anchorKey=Space`。
- **接线**：挂在场景 "Boat" 对象上（已就位）。船贴图以 **+Y 为船头**。
- **测试**：按住 W 加速到顶后匀速；按住 A/D 约 1s 后持续转向、松开停；Space 抛锚 2s 停死。

### ✅ 相机跟随 — `CameraFollow`
- **设计**：俯视跟随，`lockToTarget` 默认锁定船在屏幕中央；保留 z，正交俯视。
- **关键文件**：`Scripts\Camera\CameraFollow.cs`。挂在 Main Camera、`target` = Boat（已接线）。
- **测试**：开船时船始终居中。

### 🔧 雷达 / 声呐（声呐环扩散揭示 + 旋转扫描线、三频段同显、主线光点）
- **规则**：
  - 主画面即雷达。**声呐扫描环是唯一揭示机制**（`useRingScan=true`）：每隔 `ringInterval`（默认 2s）从船中心扩散一个圆环（由小变大、同时渐隐），波前半径到达某物品距离时该物品闪现（`SonarTarget.OnPing`，alpha 0→1→0）；越远的物品越晚被扫到，呈声呐脉冲感。
  - **旋转扫描线为纯视觉**（`showSweepLine=true`）：一根带渐隐拖尾的光束绕船以 **世界绝对方位** 旋转（默认 `sweepSpeed=120°/s`，≈3s 一圈），**不触发揭示**，仅作雷达仪表感。
  - 环与线**均程序化生成 LineRenderer**（雷达绿），**无需美术资源、无需额外场景接线**（复用 `boat` 字段，每帧跟随船）。可调：环 `ringInterval`/`ringDuration`/`ringStartRadius`/`ringPoints`/`ringWidth`/`ringColor`；线 `sweepSpeed`/`drawLeadingLine`/`beamTrailDegrees`/`beamWidth`/`beamColor`；共用 `sweepMaterial`(可选)。
  - 关闭 `useRingScan` 时回退**旧的全闪模式**：每 `refreshInterval`（默认 2s）令 `detectionRange`（默认 8）范围内物体**同时**闪现一次（`showSweepLine` 仍可独立显示扫描线）。
  - 三频段物体**同时显示**，靠各自贴图/颜色区分；切换频段不改变可见物体。
  - 主线目标（`isObjective`）始终常亮为光点。
- **频段 `SonarBand`**：Low = 1Hz–1kHz / Mid = 1kHz–2kHz / High = 2kHz–200kHz。
- **关键文件**：`SonarSystem.cs`（单例，调度）、`SonarTarget.cs`（每个物体）、`SonarBand.cs`。
- **场景接线（待做）**：新建空 "SonarSystem" 挂 `SonarSystem`，把 Boat 拖入 `boat`；建 3–4 个 Target（SpriteRenderer + `SonarTarget`，设 `band`）散布船周围；建 1 个 Objective（`isObjective=true`）。
- **测试**：每 2s 一个绿环从船中心向外扩散，波前扫到范围内物体时该物体闪现（越远越晚）；扫描线同时绕船旋转（**纯视觉，不影响闪现**）；Objective 常亮；按 Q/E 或 1/2/3 切频段，可见物体不变。关 `useRingScan` 则回到每 2s 全闪；关 `showSweepLine` 仅隐藏扫描线。

### 🔧 ping 听声（点 ping 按钮播放当前频段物体声音、音量随距离）
- **规则**：切换频段后，**点 UI 上的 ping 按钮**（Button 的 OnClick 调用 `SonarSystem.Ping()`），当前频段、范围内的每个物体各自用 3D `AudioSource` 一次性发声；音量随到船的距离衰减（越近越响），带左右方向。视觉扫描仍每 2 秒自动一次，与听声相互独立。
- **音频来源**：物体未设 `overrideClip` 时用 `SonarSystem.bandClips[band]`（用户提供）。
- **关键前提**：`AudioListener` 必须在**船**上（从 Main Camera 移过来，全场景只留一个）——否则听者在 z=-10，距离差异被压平。
- **关键文件**：`SonarTarget.cs`（`[RequireComponent(AudioSource)]`，3D：`spatialBlend=1`、对数衰减、`maxDistance=audioMaxDistance` 默认 8，`PlayPingSound` 一次性播放）、`SonarSystem.cs`（公开 `Ping()`，供 UI Button 的 OnClick 调用）。
- **场景接线（待做）**：把 AudioListener 移到 Boat；给 `SonarSystem.bandClips` 赋 3 段音频（或给 Target 设 `overrideClip`）。
- **测试**：切到某频段按一下 F（ping），该频段、范围内物体发声、越近越响、有方向；切频段后再 ping 听新频段；靠近/远离音量变化。

## 5. 输入速查
| 按键 | 作用 |
|---|---|
| `W` / `↑` | 加速（到 maxSpeed） |
| `A` `D` / `←` `→` | 左 / 右转向（持续按住 1s 后生效） |
| `Space` | 抛锚（2s 减速到 0） |
| `Q` / `E` | 上一 / 下一频段（循环 Low↔Mid↔High） |
| `1` `2` `3` | 直接切换频段 Low / Mid / High |

> 移动 / 转向 / 抛锚 / 切频段均为 KeyCode 直读，互不冲突。**ping 为 UI 按钮**（鼠标点击，调用 `SonarSystem.Ping()`），非键盘。

## 6. 运行与测试
1. Unity 打开 `MainScene` → Play。
2. 移动：W 加速、A/D 转向、Space 抛锚（见上）。
3. 雷达：每 2s 一个绿环从船中心向外扩散，波前扫到范围内物体时闪现（越远越晚）；扫描线同时旋转（纯视觉，不影响闪现）；Objective 常亮。关 `useRingScan` 则每 2s 全闪；关 `showSweepLine` 仅隐藏扫描线。
4. 频段：Q/E 循环或 1/2/3 直接切换（HUD 文本变化，可见物体不变）。
5. ping 听声：切频段后**点 ping 按钮**，当前频段、范围内物体 3D 发声、越近越响、带方向；再切频段需再点 ping。
6. 范围：开船靠近/远离物体，观察闪现与音量变化。

## 7. 路线图（建议优先级）

## 8. 约定
- 命名空间统一 `GameJam2026`。
- 移动用 **Transform + 手写速度积分**（不用 Rigidbody），便于精确控制延迟与线性减速。
- 全局管理用单例风格（`Instance`），仅在确需全局访问时使用（`GameManager` / `SonarSystem` / `UIManager`）。
- 代码注释与 Inspector Tooltip 用中文。
- 新功能优先复用现有脚本 / 钩子（如 `BoatController.Interact()`、`EventBus`）。
